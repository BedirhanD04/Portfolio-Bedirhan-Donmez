# 🚀 Portfolio Website - Bedirhan Donmez

Velkommen til mit personlige portfolio! Dette projekt er bygget til at præsentere mine projekter, tekniske kompetencer og baggrund som softwareudviklingselev på TEC Ballerup.

---

## 📌 Latest Release Notes / Opdateringer

### 🔄 Version 2.0.0 - Migration to Next.js & Node.js
* **Stack Update:** Projektet er blevet migreret fra ren HTML/CSS til **Next.js (App Router)** og **Node.js** miljø.
* **Component Architecture:** Koden er nu opdelt i rene, genanvendelige React-komponenter (`src/app/page.tsx`).
* **Performance:** Hurtigere indlæsning og bedre optimering via Next.js bundler (Turbopack).
* **Code Cleanup:** Fjernet overflødige filer og scripts for at holde projektet så rent og vedligeholdelsesvenligt som muligt.
